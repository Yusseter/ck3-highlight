## Changes

- Rename the extension to CK3 Syntax (`Yusseter.ck3-syntax`), retaining CK3 language IDs, settings and formatter command compatibility.
- Detect CK3 scripts and resources in game/mod projects, with dedicated CK3 Script and CK3 Localization language modes.
- Provide `.yml` localization highlighting with optional numeric entry versions, inline comments, escaped characters, macros and RGB formatting headers.
- Preserve quoted text, comments, indentation settings and line endings when formatting CK3 scripts.
- Give CK3 formatting its own command so it can coexist with Paradox Highlight.
- Keep scripted-parameter highlighting current across unsaved edits, filesystem changes and mod overrides. Mod folders, internal descriptors and launcher descriptors use shared path resolution.
- Add project-scoped coverage for additional vanilla CK3 text formats, readable grammar sources and keyword lists, offline builds, and pinned Tiger provenance.
- Add language file icons and an attributed MIT-licensed 256x256 extension icon from Paradox Modding Tools.

## Compatibility

- Requires VS Code 1.107 or newer.
- Language IDs are `ck3` and `ck3-localization`. Use Change Language Mode when explicit file associations select a different language.
- The Format CK3 Scripts command uses `ck3Highlight.format`.
- Configure the game and mod paths in a trusted workspace to include vanilla and dependent-mod definitions.
- Project-specific contributions use GPL-3.0-or-later. The package and repository retain third-party license texts and attribution.
